# ഇതെന്ത് കണക്ക്? (Ithenth Kanakku?)

A playful React/Vite calculator that gives correct answers in the least useful way possible.

## Features

- **അനാവശ്യം:** equivalent equations instead of plain answers.
- **അമിതം:** fake steps, conversions, and repeated verification.
- **അസംബന്ധം:** random next-number predictions with absurd confidence.
- A responsive retro interface with Malayalam labels, sarcastic commentary, and `Make it Worse` escalation.

## Development

```bash
npm install
npm run dev
```

Build and lint commands:

```bash
npm run build
npm run lint
```
