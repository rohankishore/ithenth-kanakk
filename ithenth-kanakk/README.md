# ഇതെന്ത് കണക്ക്? (Ithenth Kanakku?)

Live demo: https://ithenth-kanakk.vercel.app

A playful React/Vite calculator that gives unreliable answers in the least useful way possible.

## Features

- **അനാവശ്യം:** equivalent equations instead of plain answers, usually wrong.
- **അമിതം:** fake steps, conversions, and repeated verification before a suspicious result.
- **അസംബന്ധം:** random next-number predictions, digit shifting, and absurd confidence.
- A responsive retro interface with Malayalam labels, sarcastic commentary, and `Make it Worse` escalation.
- Achievements, meme popups, fake settings, broken dark mode, and rapid-click interruptions.

## Development

```bash
npm install
npm run dev
```
